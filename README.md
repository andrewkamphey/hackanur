# Hackanur

Website for **Hackanur**, a community-run group of indie makers, coders, designers and hardware hackers in Sanur, Bali. We co-work and demo every Thursday.

Part of the [HACKA* NETWORK](https://hacka.network/).

Live at **https://hackanur.com**, a single static `index.html` served by GitHub Pages from the `main` branch root.

## Editing

Everything is in `index.html` (markup + styles in one file, no build step). Edit it and push to `main`; Pages redeploys in about a minute.
